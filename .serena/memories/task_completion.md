# Post-Task Completion Guidelines

## Verification
- `just format`: Format the code
- `just lint`: Lint the code
- `just test`: Ensure all tests pass

## Documentation
- If the logic changes, update `README.md` or `SPEC.md`.
- If new tags are added, update tag reference in `README.md`.

## Git Workflow
- `git add .` and `git commit -m "..."`: Checkpoint your changes.
- `git diff`: Review changes before committing or responding.

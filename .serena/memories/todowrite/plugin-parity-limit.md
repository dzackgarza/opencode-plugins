Built-in OpenCode todowrite parity is split: plugin-shadowed tools can match tool-part rendering by returning the upstream JSON output string and mutating title/metadata in `tool.execute.after`, but they cannot match session sidebar/store behavior because upstream uses `Todo.update()` + `Bus.publish(todo.updated)` and the plugin SDK exposes neither a todo write endpoint nor a generic event emitter. For FastMCP parity, `mcp-shim/run-tool.ts` now needs to run plugin tool hooks and preserve structured `{title, output, metadata}` results.

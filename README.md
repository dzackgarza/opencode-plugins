# OpenCode Plugins

Collection of standalone OpenCode plugin packages and shared support code.

## Plugins

- **[improved-task](./improved-task/README.md)**: Plugin-backed task management.
- **[improved-todowrite](./improved-todowrite/README.md)**: Hierarchical todo tree tools with MCP wrapper.
- **[improved-webtools](./improved-webtools/README.md)**: Web fetching and searching tools with MCP wrapper.
- **[prompt-router](./prompt-router/README.md)**: Prompt-tier routing hook.
- **[mcp-shim](./mcp-shim/README.md)**: Shared TypeScript executor for MCP wrappers.
- **[zotero](./zotero/README.md)**: Python Zotero toolkit and skill materials.

Refer to individual package READMEs for installation, dependencies, and tool schemas.
